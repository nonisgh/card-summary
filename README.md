# カード明細集計

三井住友カード（VISA / Mastercard / Olive）と マネーフォワード ME の CSV をドロップして、
自分で決めた種別マスタで集計する HTML 1 枚のアプリ。

- 公開URL: https://nonisgh.github.io/card-summary/
- データは Firebase（プロジェクト `nonis-apps`、ab-editor と共用）の Firestore。Google でログインする。
  - 置き場所は `apps/card-summary/users/{uid}/` の下：`statements/{カード}_{月}`（その月の明細を JSON でまとめて 1 件）、`snapshots/{card|mf}_{月}`（月の記録）、`settings/master`（種別マスタ）。
  - `firestore.rules`（ab-editor のリポジトリにある、プロジェクト共通のルール）で、本人しか読み書きできない。
  - GitHub Pages から Google ログインするには、Firebase コンソール → Authentication → 設定 → 承認済みドメイン に `nonisgh.github.io` を入れておく。
- 前のバージョンは Supabase（`supabase.sql`）。Firebase にまだ何もないときは、画面の「Supabase から引っこす」でまるごとコピーできる。
- ログインしていないときは、そのブラウザ（localStorage）だけに保存する。

## CSV

- 確定前（速報）: 利用金額（7列目）を使う。請求月は CSV の「'26/11」列から。
- CSV はいつでもどんどん入れてよい。自動で保存し、カードは請求月ごと（同じカード・同じ請求月は自動で上書き）、マネーフォワードはファイルの期間（ファイル名の日付、なければ最初〜最後の日）だけ上書きする。デビットの仮の名前（V〜）も、あとのCSVで確定した名前に置きかわる。
- 各月の記録（明細・分類・集計）は自動で残り、明細を「管理」から消しても見返せる。「明細DB」タブで月をまたいで検索できる。
- 確定後: 支払金額（6列目）を使い、最後の行のご請求額と一致するかチェックする。請求月はファイル名の YYYYMM から。
- VISA と Mastercard は CSV では区別できないので、ファイル名の最後（拡張子の前）の 1 文字で決める：`v`=VISA、`m`=Mastercard、`o`=Olive（例：`202611v.csv`）。
  この名前なら、カード画面のどこにまとめてドロップしても自動で振りわける。名前に印がないファイルは、ドロップした箱のカードになる。
- その月に使っていないカードは、箱の「この月はなし」にチェックする。ぜんぶのカードが「CSVあり」か「なし」になると「そろっています ✓」と出る。あとでCSVを入れると、そちらに置きかわる。

## 種別マスタ

A列=パターン、B列=表示名、C列以降=集計軸、「タグ」列=カンマ区切りのタグ。
パターンの `*` はどこに書いても「なんでもOK」。大文字小文字・全角半角・スペースの数はそろえてから比べる。
集計軸の名前に `*` を入れると、その軸は集計しない。
